# Personal Portfolio Website

## Intro

Build me an Awwwards-worthy personal portfolio website in Next.js 14+ (App Router) that showcases my work as a software engineer. Use my resume (attached) as the data source for experience, projects, and skills.

## Design

- Modern, minimalist aesthetic with sophisticated micro-interactions and smooth animations (Framer Motion)
- Clean typography hierarchy - think Vercel/Linear vibes with generous whitespace
- Subtle glassmorphism effects and gradient accents
- Supportive of both dark and light mode, using the color palette of #011935, #012550, #8A9CB2, #D4D4D6, #EBECEA, #F1F1F1.
- Responsive, mobile-first design with buttery smooth scrolling
- Typography has to be crisp and legible - consider using variable fonts for performance and aesthetics. I would like some variations between all caps, small caps, font boldness, sizes, widths, and spaces where appropriate.
- Make typography animations--like fade-ins, glitch some letters, strikethrough, slide-ups, and typewriter effects--to add personality without overwhelming the content.

## Structure

- Hero: Bold introduction with animated text, role, and CTA. Make a typewriter effect for an intro line about me.
- About: Short bio covering my background (MBA student at BYU, musician in Ritt Momney, Korean speaker, love building dev tools and compliance automation)
- Experience: Horizontally scrolling timeline view of roles with expandable details, tech stacks as pills/badges
- Projects: Card grid showcasing KeyCoach, Kearl, Lecture Transcriber with GitHub links, live demos where applicable, and tech stack visualizations
- Skills: Interactive visualization (consider a tag cloud, skill bars, or categorized grid)
- Contact: Simple form or social links (LinkedIn, GitHub, email)

## Tech Stack

- Next.js 14+ with App Router, TypeScript, TailwindCSS
- Framer Motion for animations (scroll-triggered reveals, hover effects, page transitions)
- shadcn/ui components (or other fitting components) where appropriate
- Optimized images with next/image
- SEO optimized (metadata, og tags)
- Deploy-ready for AWS Amplify or Vercel

## Tone & Feel

- I want it to feel cozy yet sharp, technical yet balanced, and creative yet professional - showcase both my engineering chops and my creative side (music, design thinking, gaming). Think somewhere between a dev tool landing page and a creative portfolio. Professional but not boring, technical but approachable.
- Use the resume data to auto-populate content, but feel free to suggest copy improvements for web presentation. Include hover states, smooth transitions, and delightful micro-interactions throughout.
- Use the example images of Awwwards-winning sites for inspiration, but don't feel like you need to copy exactly.
- Make it memorable.
