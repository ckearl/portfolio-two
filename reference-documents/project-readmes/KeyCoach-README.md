# KeyCoach README

## Introduction

I don't have a README for KeyCoach yet, but this is a description that I've written out before:

KeyCoach - This was my Masters capstone. Using ML5JS, my team and I built a web-app that tracks the finger positions of a keyboardist (like computer typist) to see if they are typing with the right technique. This is done via a 3D printed mirror clip (that I designed) that gets placed over the front facing camera to reflect the camera down to the keyboard of a laptop, that way the program can see the fingers as they type. We built typing tests (with words, timed, quote-based test selection types), typing lessons, a full asteroids-style typing game, and all are able to be used while the application tracks finger positions to ensure the user is typing correctly. It gives feedback, letter accuracy (from the Hand tracking model), and typing accuracy through traditional typing test means. This was eight months of designing, programming, and testing.
